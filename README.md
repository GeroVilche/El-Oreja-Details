# El Oreja Details — Sistema de turnos

Landing page para un lavadero de autos con sistema de reserva de turnos online.

## ¿Qué hace?
El cliente completa un formulario en la web eligiendo día y horario para su turno. 
Al enviarlo, se crea automáticamente un evento en Google Calendar, y también 
permite cancelar el turno si el cliente cambia de planes.

## Tecnologías
- HTML, CSS, JavaScript (frontend)
- Node.js + Express (backend)
- Google Calendar API (creación y cancelación de eventos)
